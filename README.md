# CIP-B106 — iOS 13 Forensics

Digital forensics case study examining an authorised iPhone running iOS 13.4.1.

**Overview**

The investigation reconstructs device activity using the supplied iOS forensic image and supporting evidence.

**Examined Artefacts**

1. Device, SIM and network information

2. Apple/iCloud configuration

3. Messages, calls, contacts and calendar

4. Installed applications

5. Safari history and browser data

6. Photos and media

7. KnowledgeC activity

8. Health and location artefacts

9. Possible jailbreak indicators


**Tools**

1. DB Browser for SQLite

2. Plist utilities

3. Cellebrite Physical Analyzer / Magnet AXIOM

4. Approved forensic laboratory tools

**Methodology**

Evidence was examined from verified working copies without modifying the original material. Findings were manually validated against underlying SQLite, plist, or file-system sources where required.

Important events were documented with their raw timestamp, converted time, timezone, source, and limitations.

**Academic Use**

This project is for CIP B106: Mobile and IoT Forensics and is based on authorised training material.
